# Changelog

Notable changes to `vue3-mobile-nav` are recorded here.

## 0.2.0

- Eight animated navigation variants with shared light and dark themes.
- Configurable items, selection, destinations, badges, and disabled state.
- Native link behavior and optional Vue Router integration.
- Keyboard support, reduced-motion handling, and fixed positioning with safe-area padding.
- Live documentation playground and TypeScript exports.
